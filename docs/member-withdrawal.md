# 회원 탈퇴

`POST /api/users/me/withdrawals`에 세션·CSRF와 `{clientRequestId}`(UUID)를 보낸다. 원시 본문 상한은 1 MiB다. 성공은 `204`와 세션 쿠키 만료다.

## 처리와 보존

- 소유 공간이 남으면 `409 OWNED_SPACE_REMAINS`다. 소유권을 이전하거나 공간을 삭제해야 한다.
- 회원·소셜 계정·전체 JDBC 세션·본인 성공 요청 기록을 삭제한다. 현재 참여를 종료하고 본인 편집 잠금과 미완료 할 일의 담당을 정리한다. 기존 대기 요청은 종료된 참여로 인해 무효가 된다.
- 공동 소식·근거·확정 항목·이력은 남긴다. 공개 작성자는 `{membershipId: null, displayName: null, withdrawn: true}`로 표시한다.
- 작업은 한 트랜잭션에서 처리한다. 회원 생명주기 잠금과 V22의 세션 FK로 탈퇴 직전의 지연 요청이 기존 회원 세션을 다시 만들지 못하게 한다.

## 반복 요청과 재가입

이전 세션으로 재요청하면 `401 UNAUTHENTICATED`다. 유효한 회원의 CSRF 누락은 `403 FORBIDDEN`이다. 같은 소셜 계정으로 다시 로그인하면 새 회원 ID를 받으며 기존 역할·참여는 복원되지 않는다. FE는 탈퇴 성공 후 로그인 상태와 관련 캐시를 비운다.
